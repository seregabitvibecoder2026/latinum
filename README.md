# 🦉 Latinum — латынь в стиле Duolingo

Учим классическую латынь через английский: XP, серии дней, уровни-звания, ачивки,
комбо, тренировка ударения и настоящие цитаты Цезаря, Вергилия, Цицерона.

## Запуск
Откройте `index.html` в браузере (двойной клик). Интернет и установка не нужны.

## Прогресс — как это работает
- **Автосохранение** в браузере после каждого урока (localStorage) + автоматическая резервная копия.
- **Обновление программы:** просто заменяйте файлы в той же папке — прогресс останется.
  Для надёжности перед обновлением нажмите *Profile → Download progress file*.
- **Синхронизация устройств** (Profile → Save & Sync):
  - файл `latinum-progress-ДАТА.json` — скачать на одном устройстве, загрузить на другом;
  - или **sync-код** — короткий текст, который можно переслать себе в мессенджере.
  - Прогресс **объединяется**, а не перезаписывается: XP с обоих устройств складывается
    правильно, сохраняются лучшие уровни уроков. Объединять можно в любом порядке и сколько угодно раз.

## Звук
Латинского голоса в браузерах нет, поэтому используется испанский/итальянский голос с
переписанной орфографией и принудительным ударением. На телефонах голоса обычно есть.
На Linux без голосов звук просто выключится — ударение всё равно показано визуально.
